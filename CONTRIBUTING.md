# Contributing

Thank you for helping improve the technical material for the GDG Chennai DevFest 2026 session.

## Scope

Contributions should improve:
- technical correctness
- clarity of explanations
- reproducibility of demos
- security and evaluation examples
- documentation quality

## Before contributing

1. Read the README.
2. Keep examples provider-neutral unless a provider-specific integration is documented.
3. Never add API keys, credentials, personal data, or secrets.
4. Keep claims reproducible and provide methodology for benchmarks.
5. Prefer small, focused changes.

## Pull requests

Please describe what changed, why it changed, how it was tested, and any assumptions or limitations.

## Code style

Use clear Python, type hints where useful, small functions, and descriptive names.

## Content changes

Keep slide and documentation changes practical, technically accurate, and accessible to an intermediate developer audience.
