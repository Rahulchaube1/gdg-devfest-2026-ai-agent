# Code of Conduct

## Our standard

This project aims to be a respectful technical learning space. Participants should communicate professionally and assume good intent while remaining precise about technical disagreements.

## Expected behavior

- Be respectful and constructive.
- Focus criticism on ideas, code, and evidence.
- Welcome different experience levels.
- Avoid harassment, discrimination, personal attacks, and inappropriate conduct.
- Protect private or sensitive information.
