# Security Policy

## Scope

This repository contains conference-session demonstration code. It is not intended for production deployment without additional security review.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

Contact: **rahulchaube900@gmail.com**

Include the affected file/component, concise description, reproduction steps, potential impact, and suggested mitigation if known.

## Security principles demonstrated

- least privilege
- server-side authorization
- explicit tool contracts
- argument validation
- approval gates for consequential actions
- data minimization
- structured logging and evaluation

Never commit secrets, credentials, tokens, or private datasets.
